# Gemini AI Chatbot with Memory & Real-Time Data

## Project Overview

This project is an AI chatbot developed using Python and the
Google Gemini API.

The chatbot can have normal conversations, remember previous
messages during a conversation, and retrieve real-time information
using Google Search.

## Technologies Used

- Python
- Google Gemini API
- Google GenAI Python SDK
- Google Search
- python-dotenv

## Features

- AI-powered conversation
- Conversation memory
- Start a new conversation
- Real-time information retrieval
- Google Search integration
- Streaming responses
- Secure API key handling using environment variables
